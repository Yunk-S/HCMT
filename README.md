# HCMT: Hierarchical Clinical-Markov TransformerHCMT is a continuous-time transformer for sparse perioperative clinical event trajectories. This repository contains only the training runtime: event construction, sequence datasets, sampling, model code, and training entry points. Patient data, checkpoints, external-validation artifacts, baselines, reports, and historical code are intentionally excluded.## OverviewEach patient episode is represented as an irregular event sequence:$$\mathcal{S}_p = \{(x_i, t_i, v_i, q_i, f_i)\}_{i=1}^{n_p},$$where:- $x_i$ is an event or context token;- $t_i$ is the time in minutes from the episode origin;- $v_i$ is an optional continuous measurement;- $q_i$ identifies the token kind and observation state;- $f_i$ is the clinical event family.
